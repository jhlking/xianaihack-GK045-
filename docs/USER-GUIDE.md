## 1. 系统组成

WonderForge 由三部分组成：

| 部分 | 作用 | 访问地址 |
|---|---|---|
| 前端 `web/` | 页面界面，React 应用 | `http://localhost:5173` |
| 后端 `server/` | 接口与 AI 中转，Express 服务 | `http://localhost:8787` |
| 小云雀 XYQ | 外部 AI 能力（方案生成 + 图片生成） | 云端（需 Key） |

浏览器中的操作都会先经过本地后端，再调用小云雀；**后端未启动时页面无法正常使用**。

---

## 2. 启动与访问

详细步骤见 [START-HERE.md](../START-HERE.md)。核心三步：

1. 配置 `server/.env` 中的 `XYQ_ACCESS_KEY`
2. 启动后端（`启动服务器.bat` 或 `cd server && npm run dev`）
3. 启动前端（`cd web && npm run dev`），打开 `http://localhost:5173`

验证：浏览器访问 `http://localhost:8787/api/health`，返回 `{"ok":true,"key_configured":true}` 即正常。

## 3. 搭配工作台（核心功能）

路径：首页即 `#/combine`（导航栏「搭配工作间」）。

### 3.1 选择组合要素

页面按三个分类展示奇物库（每类 50 件）：

| 分类 | 说明 | 示例 |
|---|---|---|
| 日常物品 | 有故事的旧物 | 陶瓷马克杯、老式旋转电话机、檀木梳、八音盒… |
| 功能部件 | 硬件能力件 | LED 灯带、夜光荧光粉、微型摄像头、扬声器… |
| AI 模组 | 智能能力 | 声音克隆、记忆相册、情绪安抚、老照片修复… |

操作方式：

- 点击卡片即选中/取消（卡片出现「✓ 已选」标记），可多选
- 每张卡片下方可看到标签（如「发光」「复古」「陪伴」）辅助决策
- 功能部件与 AI 模组卡片上另有「搭配工作间」按钮：一键加入并自动滚动到工作间

> 建议组合思路：**1 件旧物 + 1~2 个部件 + 1~2 个 AI 模组**，效果最佳。

### 3.2 填写预期效果（可选）

在「预期效果」输入框写下你希望的样子，例如：

> 想给杯子加上夜光，做成夜晚会发光的记忆杯，能自动记录每次喝水的时间。

不填写也可以，AI 会自由发挥。

### 3.3 生成产品方案

点击「生成产品方案」按钮：

- 等待约 **1~3 分钟**（小云雀最长 8 分钟），期间按钮显示「生成中…」并转圈
- 生成完成后页面展示结果卡片：

| 结果区块 | 内容 |
|---|---|
| 产品名 + 介绍 | AI 起的名字与 80 字内介绍 |
| 核心玩法 | 2~3 条玩法 |
| 材料清单 | 需要的材料 |
| 组装步骤 | 3~5 步 |
| 效果图 | 照片级效果图（发光质感），可右键另存 |
| 视频预留位 | 二期接入视频生成的占位区域 |
| 会话链接 | 「在小云雀查看」跳转原始 AI 会话（若返回） |

> 若第一轮没出图，系统会拿「英文外观描述」在同一会话里自动补一张效果图，无需你干预。

### 3.4 组合记录

- 每次生成成功会自动存入「组合记录」（最多 **20 条**，超出自动丢弃最早一条）
- 每条记录展示产品名、所选物品与生成时间
- 「载入」一键恢复当时的选物、预期与结果；「删除」移除单条；「清空记录」全部清空
- 当前选择会自动**保存为草稿**，刷新页面后仍在

## 4. 明星组合工作台

在搭配工作间里，部分旧物卡片带有「搭配工作间 →」链接（如老式电话机、木质相框、复古台灯、老式收音机、机械怀表、搪瓷暖水壶等），点击进入该旧物的专属工作台 `#/combine/:slug`。

### 4.1 图片型工作台

以预设旧物为主角，展示「改造前 → 改造后」效果图对比：

- **可添加部件 / AI 模组**：点击卡片切换「添加 / 注入」，右侧效果图实时切换（原样 / 单部件 / 双部件）
- **效果图缩略图**：点击快速切换不同组合状态
- **AI 面板示意**：注入 AI 模组后出现示意面板（演示环境，正式版接入真实 AI 能力）
- **带去组合工作台生成方案**：把当前开关状态一键带入 `#/combine` 生成 AI 方案

### 4.2 3D 型工作台

「时光电话」「心愿病房」为 3D 交互工作台，直接在页面内操作 3D 场景（拖拽旋转视角、滚轮缩放），页面底部有「试试这样玩」操作提示。

## 5. 3D 演示

导航栏「3D 演示」（`#/demos`）进入演示大厅，三件明星组合：

| Demo | 组合 | 玩法 |
|---|---|---|
| 时光电话 `#/demo/phone` | 复古电话机 × AI 声音模组 | 拖动听筒接听、拨号盘拨号、听记忆里的声音 |
| 声纹梳 `#/demo/comb` | 梳子 × 声音录制模组 | 采集与回放声音 |
| 心愿病房 `#/demo/ward` | AI 视频 × 声音 × 信息提取 | 按下红色按钮，屏幕里亲人说出「我爱你」 |

每个 demo 基于 Three.js 构建，支持鼠标拖拽旋转与滚轮缩放。

## 6. 社区

导航栏「社区」（`#/community`）—— 一起共创的构想广场。

### 6.1 浏览构想

页面列出全部构想卡片：标题、目标、组合（如「陶瓷马克杯 × 夜光荧光粉」）、状态（征集中 / 组装中 / 效果图已生成）、助力列表。

首次启动内置 3 个种子构想；社区数据写入 `data/community.json`。

### 6.2 发起构想

点击「+ 发起构想」：

- **构想标题**：最多 80 字，例如「夜光记忆杯」
- **预期目标**：最多 1000 字，描述你希望它变成什么样

提交后构想出现在列表顶部，状态为「征集中」。

### 6.3 助力他人构想

在任一构想卡片选择「助力」，四种助力类型：

| 类型 | 说明 |
|---|---|
| 加模组 | 建议增加的功能模块 |
| 改 3D 图纸 | 上传或修改图纸 |
| 提方案 | 整体方案建议 |
| 供物料 | 提供材料 |

可填写助力内容（≤1000 字），也可上传 3D 图纸文件（STL / STEP / STP / 3MF / OBJ，单个 ≤ 20MB），图纸存到 `server/public/uploads/` 并在助力记录中展示下载链接。

> 提示：社区数据保存在服务器本地 `data/community.json`，重启不丢失；该文件被 `.gitignore` 忽略，不会随代码提交。

## 7. 数据存储说明

| 数据 | 存储位置 | 生命周期 |
|---|---|---|
| 组合草稿 | 浏览器 localStorage（键 `wonder-forge:combiner:draft`） | 永久（清站点数据才丢） |
| 组合记录 | 浏览器 localStorage（键 `wonder-forge:combiner:history`，最多 20 条） | 永久（可手动清空） |
| 社区构想 | 服务器 `data/community.json` | 永久（本地文件） |
| 上传图纸 | 服务器 `server/public/uploads/` | 永久（本地文件） |
| 生成效果图 | 服务器 `server/public/generated/`（小云雀图片落地缓存） | 永久（本地文件） |

> 换浏览器或清除站点数据会丢失草稿与历史；社区与生成图存在服务器上不受影响。

## 8. 常见问题与技巧

**Q：生成结果没有图片？**
A：首轮未出图会自动补图；若仍无图，页面显示「效果图生成中或未返回」，可重新生成。图片落地失败时退回原始外链。

**Q：生成的图片能保存到本地吗？**
A：可以。效果图右键「图片另存为」；图片同时缓存在 `server/public/generated/` 目录。

**Q：页面提示「出错了：…」？**
A：多为后端未启动、Key 未配置或网络不通。依次检查 `server/.env`、后端健康接口、网络环境。

**Q：想让 AI 方案更贴合需求？**
A：在「预期效果」里写具体些（材质、颜色、使用场景、目标人群），AI 的方案会更精准。

**Q：生成太慢怎么办？**
A：每次生成约 1~3 分钟，建议一次选好再点生成；组合记录支持「载入」复用，减少重复操作。
